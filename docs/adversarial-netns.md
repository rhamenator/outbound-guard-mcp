# Isolated socket probe

`bash tools/netns_adversarial_probe.sh target/debug/outbound-guard-mcp` runs the built MCP server against DNS and HTTP fixtures inside a disposable Linux network namespace. The namespace has no external route. Its only approved address, `11.0.0.1`, is assigned to its own loopback interface; the host's DNS and firewall configuration are untouched. The script needs `sudo -n`, `iproute2`, and Python 3. It removes the namespace and its private resolver configuration on exit.

The probe sends actual MCP `tools/call` requests. Private-only and mixed public/private DNS answers must produce `EGRESS_FORBIDDEN_ADDRESS` with zero HTTP requests. A synthetic AWS-shaped token in the URL must be denied before DNS or HTTP, without appearing in the result. An approved hostname must return its plain-text response even when `HTTP_PROXY` and `ALL_PROXY` (including lowercase variants) point to a dead local proxy. Redirect, gzip-encoded, and declared oversized responses must produce their respective denial codes. Conflicting Content-Length/Transfer-Encoding and duplicate Content-Length responses must fail closed; reqwest may reject either during parsing as `EGRESS_NETWORK_FAILURE` before the guard can emit `EGRESS_INVALID_FRAMING`. A chunked response with no declared length must hit the byte cap. A rebinding fixture changes its A answer from the isolated public address to loopback after the first lookup; the direct fetch succeeds and reports the number of A queries. Delayed headers, a one-byte-per-second body, and EOF just after the total deadline must fail within 16 seconds, without a partial body in the result. The body cases guard against a per-read timeout being reset by every arriving byte and late EOF being accepted as safe. CI runs the same fixture after building the binary.

This is socket-level evidence for these fourteen cases, not a full adversarial certification. The current rebinding run sees one A query, so it does not prove behavior on a reconnect or a second resolver call. The slow-drip denial proves a total response deadline, not a sliding byte-rate detector. The secret probe covers one known-token pattern in a URL, not arbitrary exfiltration. Malformed framing coverage is limited to the two header conflicts above. Decompression expansion, TLS hostname mismatch, concurrent resource exhaustion, and real-client use remain release gates in [QUALITY_BAR.md](QUALITY_BAR.md). It also cannot govern traffic an agent sends through other tools.
