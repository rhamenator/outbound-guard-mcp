# Contributing

Open or link an issue for non-trivial work. Keep pull requests focused and explain behavior, interfaces, and security impact. Add relevant regression tests and run the documented checks. Complete the pull request evidence sections. Do not commit secrets, personal data, generated artifacts, or unrelated changes.

Security reports follow [SECURITY.md](SECURITY.md). Change control follows [the assurance policy](docs/DO-178C-ASSURANCE-POLICY.md); this is an engineering baseline, not a certification claim.
